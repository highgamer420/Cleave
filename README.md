ABOUT CLEAVE
Built to make multicolor 3D printing easier.

Cleave is a 3D model preparation tool designed to turn multicolor models into separate, printable parts.

Instead of manually cutting models apart, guessing where to make the cuts, or trying to line pieces back up after printing, Cleave analyzes the color and material regions already built into your model and uses those boundaries to create clean separations.

SPLIT WITH PURPOSE.

Cleave isn't just another model-cutting tool.

It is built around one simple idea:

If your model already knows where the colors belong, why should you have to guess where to split it?

Cleave follows the existing color regions in your model and creates cuts along those natural boundaries. Each resulting piece can then be exported and printed separately.
